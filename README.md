# 啤酒灌装流水线 3D 运行仿真

基于 Three.js 的啤酒灌装车间 3D 仿真，中文界面。空瓶经**洗瓶 → 多头灌装 → 压盖 → 贴标**后由出料台排出，随机故障瓶由拨杆剔到旁侧回收道。

## 运行方式

ES Module 不能直接用 `file://` 打开，需在项目根目录启动静态服务器：

```bash
# 任选其一
npx serve .
# 或
python -m http.server 8080
```

然后浏览器访问 `http://localhost:端口/`（需要联网加载 jsDelivr 上的 Three.js）。

## 目录结构

```
├── index.html          # 页面与中文控制面板
├── css/style.css       # 面板样式
├── js/
│   ├── config.js       # 灯光/车间/节拍/故障概率/模型路径集中配置
│   ├── factory.js      # 几何体兜底模型 + GLTFLoader 加载
│   ├── simulation.js   # 仿真核心：输送进度、工位节拍、故障与剔瓶
│   └── main.js         # 渲染器、相机机位、鼠标交互、UI 绑定
└── models/             # 放置 glTF 模型（可选）
    ├── washer.glb
    ├── filler.glb
    ├── capper.glb
    └── labeler.glb
```

## glTF 模型复用

模型路径在 `js/config.js` 的 `modelUrls` 中统一管理，可换为在线 URL（如 `https://.../washer.glb`）或本地路径。
任一模型加载失败（404 / 网络错误 / 解析失败）都会**自动回退到内置几何体模型**，并在页面顶部弹出提示，仿真功能不受影响。

## 功能一览

- **控制**：全线启动 / 暂停 / 急停 / 复位，线速滑块（0.5×–2×），330ml/500ml 容量切换，三种瓶身配色，随机故障开关，外墙显隐。
- **数据**：当前线速、已灌装瓶数、合格/剔除数、合格率、四工位状态（待机/运行/堵塞）、故障日志。
- **故障**：瓶子歪倒（洗瓶机）、灌装未满（灌装机）、标签歪斜（贴标机），对应工位亮红灯，拨杆把问题瓶拨到回收道。
- **机位**：全线俯视、跟随单瓶流转、工位特写；左键环绕、滚轮缩放、右键平移。
- **交互**：点击任意工位查看设备名称与当前工序说明。
- **动画**：输送链与端部滚筒、星轮、六头灌装阀旋转与下行注液、压盖头往复、贴标滚轮转动、液位随灌装时间插值上升。

## 自动化验证

`tests/logic-test.mjs` 用 mock 的 Three.js 直接驱动仿真核心跑 60 秒，校验计数平衡、合格率区间和故障与工位的对应关系：

```bash
node tests/logic-test.mjs
```

页面还内置两个仅测试用的 URL 钩子（正常使用不受影响）：

- `index.html#autostart`：打开页面后自动开线；
- `index.html#autostart-headless`：额外用定时器补驱动，规避无头浏览器虚拟时间下 `requestAnimationFrame` 不触发的问题。
